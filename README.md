# Bopl Battle Synergy Mod

Мод добавляет систему синергий между способностями. При одновременном нажатии двух кнопок способностей активируется специальный комбинированный эффект.

## Синергии

### 1. Луч + Размножение
- Стреляет 3 лучами под углами (центр, +45°, -45°)
- Применяет отталкивание игрока назад

### 2. Луч + Увеличение
- Луч увеличивает объекты
- Одновременно уменьшает игрока
- Останавливается при достижении минимального размера

### 3. Луч + Перемещение
- Луч притягивает объекты к игроку
- Постепенное притягивание через физику

## Установка

1. Убедитесь что установлен BepInEx 5.4.21+
2. Скопируйте `BoplSynergyMod.dll` в `BepInEx/plugins/`
3. Запустите игру

## Сборка

```bash
dotnet build -c Release
```

Или используйте `build.bat` (Windows)

## Требования

- BepInEx 5.4.21+
- Bopl Battle (Steam версия)
- .NET Framework 4.7.1
